# Política de seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades, credenciales, datos personales ni instrucciones
de explotación en un issue público.

Utiliza **Security > Report a vulnerability** en GitHub para enviar un reporte
privado mediante GitHub Security Advisories. Incluye:

- versión o commit afectado;
- impacto estimado;
- pasos mínimos para reproducirlo;
- mitigación propuesta, si la conoces.

Se confirmará la recepción y se coordinará la publicación de la corrección antes
de hacer públicos los detalles.

## Alcance sensible

Presta especial atención a:

- autenticación, sesiones y MFA;
- permisos de administradores, jugadores y tutores;
- acceso a PDFs, fotos, justificantes y documentos privados;
- anonimización RGPD y trazabilidad contable;
- secretos de despliegue y almacenamiento.

Nunca uses datos reales de jugadores o familias para demostrar un problema.
